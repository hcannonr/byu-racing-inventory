# Workshop icon artwork

Generated October 5, 2026 through Higgsfield's REST API using the operator's existing API key. Credentials were only read by a local generation script and are not part of the app.

`workshop-sheet.png` is the original 2496 × 1664 output from `xai/grok-imagine-image-2.0`, 2k, medium. Six illustrations occupy a 3-column, 2-row grid. CSS uses background positions to display individual cells without changing the source pixels.

- Top row: working bin, reserve bin, empty bin.
- Bottom row: bolt/nut, electrical crimp, package.

Bin numbers and status labels remain HTML so artwork never determines inventory state. Small functional controls continue using Lucide icons.

Cost quotes: six initial Recraft drafts at $0.035 each ($0.21) plus the final sheet at $0.08, totaling $0.29 against a $1.50 limit. All seven requests completed. Drafts and the request/quote ledger are archived outside the served app in `projects/byu-racing-inventory/archives/icon-drafts-2026-10-05/`. A token-priced model was estimated but not submitted because it did not return a numeric USD quote. No subscription, balance top-up, or app-side image-generation integration was added.
